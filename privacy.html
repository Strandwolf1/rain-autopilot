Privacy policy

Last updated: 16 November 2026

Rain Autopilot is a personal tool run by a single creator for their own YouTube channels. It is not offered to the public.

What it accesses

When the owner signs in with Google, the tool receives permission to manage the owner's YouTube channels (YouTube Data API scopes youtube.upload and youtube.force-ssl). It uses this only to upload and schedule the owner's videos, set their details and thumbnails, add captions, and manage playlists.

What it stores

The sign-in token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. No information about other people is collected.

Google API data

Rain Autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
